# 亡者世界 · 生存图鉴

一个离线优先的手机攻略 APP，面向《亡者世界》（DeceasedCraft - Urban Zombie Apocalypse）整合包 **5.11.19**。

底部五个板块：

- **战利品**：8 个区域 / 104 座建筑（282 个建筑区块）/ 13,330 条掉落 / 2,116 种物品 / 89 条建筑方块记录。区域按气候配色，只有荒地（wasteland）带黄黑警戒条纹与闪烁 ☢️；荒野（wild）与街道（street）不绑定 T3/T4，按 T1–T3 均有处理，不显示辐射警告；建筑名后标注**尸潮（2–5 个僵尸头颅）/ 体型**徽标，不再显示枪械产出标签。可按区域 → 建筑 → 区块 → 楼层 → 容器逐层查看，也可以直接搜物品，反向查“这个东西哪里刷、掉率多少”。
- **生物**：
  - **怪物**：图鉴数据 **167 种**（真菌 54 + 非真菌可刷新 113），**全部有图**；旧版联网种子中的预览/非刷新怪物已不再混入。按普通感染体 / 特殊感染体 / 变异体 / 感染动物 / Boss / 尸潮 / 武装人类分类，并只按**普通 / 特殊 / 小头目 / 头领 / 灾厄 / 真菌**威胁等级筛选；不再按辐射区域分组。
  - **NPC** 19 个，分为友军 / 敌对 / 雇佣兵，带生命、伤害、护甲、武器、具体位置与**交易清单**（逐条显示支付 → 获得、货币/以物易物、价格与库存；区域用气候颜色标记）。
- **装备**：29 套护甲套装（T1–T4，含 3 款机械动力喷气背包）、177 把 TACZ 枪械、**141 件按 FTB 任务书修复材料严格分为 T1–T4、并标注游戏内伤害/攻速/单双手的近战武器**、57 件饰品；新增独立**改枪台**（177 把枪 / 197 个配件）。
- **世界**：四个板块「世界难度 / 载具 / 剧情故事 / 防御工事」。118 种载具（109 种已补组装配方）、33 条防御工事、106 篇剧情书。
- **我的**：收藏、自制怪物、导入导出备份。

收藏、自制条目、补充内容都会保存在本机，不需要账号，也不会上传。

## 二、怎么装到手机上

### 方式 A：直接打开单文件版（最快、真正离线）

把 **`亡者世界图鉴-单文件版.html`** 发到手机（微信文件传输助手 / QQ / 数据线均可），用浏览器打开。

- **轻量版**：如果手机打开 41 MB 完整版卡顿或白屏，改用 `亡者世界图鉴-单文件版-轻量无音乐.html`（约 27 MB）。页面、数据、图片完整，只是不内嵌 7 首音乐。
- **修复版**：`亡者世界图鉴-单文件版-修复版.html` 与完整版内容相同，用于避开旧文件缓存。

- 优点：一个文件，完全离线，不依赖电脑和网络；图片和 7 首音乐都已内嵌。
- 限制：通过 `file://` 打开时，部分浏览器会限制本地存储，收藏/自制内容可能无法保存；也没有“添加到主屏幕”的安装入口。
- 适合：临时查资料、把攻略发给朋友。

### 方式 B：本地服务（同一 WiFi 下使用）

1. 电脑上双击 **`app/start-server.bat`**。
2. 记下电脑的局域网 IP（命令行运行 `ipconfig`，找 IPv4 地址，例如 `192.168.1.23`）。
3. 手机和电脑连同一个 WiFi，手机浏览器访问：`http://192.168.1.23:8787`。

这个方式适合“电脑开着，手机当第二屏查资料”。注意：局域网 `http://` 通常不是安全上下文，浏览器可能不会注册 Service Worker，**不能保证电脑关机后还能离线打开**。要真正离线安装，请用方式 A 或方式 C。

### 方式 C：部署到 HTTPS 静态托管（安装 + 离线，推荐长期使用）

把 **`app` 文件夹**上传到任意支持 HTTPS 的静态托管（GitHub Pages、Netlify、Vercel、Cloudflare Pages 等），手机访问 HTTPS 地址后安装：

- **Android（Chrome / Edge）**：右上角菜单 → 「安装应用」。
- **iPhone（Safari）**：底部「分享」→「添加到主屏幕」。

HTTPS 环境下 Service Worker 才能正常工作，安装后即使断网也能从缓存打开。音乐文件已加入离线缓存（`audio/` 目录，约 11 MB）。朋友也可以通过同一个网址安装，不需要后端。

## 三、功能说明

### 战利品

- 首页按区域浏览，每个区域显示建筑数、掉落条目数、温度档位。
- **气候配色**：温暖（绿）/ 炎热（橙红）/ 寒冷（蓝）/ 辐射（暗黄 + 黄黑警戒条纹）/ 炎热·寒冷（双色）。荒野与街道现在同时标注炎热和寒冷。
- **区域封面**：T3 寒冷区「零售商业区」封面固定使用露台购物中心。只有荒地（wasteland）卡片与详情页带闪烁红色 ☢️ 和页首固定红色加粗横幅「⚠️ 高辐射区域，请穿戴防护服并携带抗辐射药剂」；荒野（wild）与街道（street）按 T1–T3 均有处理，不再绑定 T3/T4，也不出现辐射警告。
- **建筑徽标**：建筑名后显示尸潮建筑标记——按建筑规模显示 **2–5 个僵尸头颅**，尸潮越大头颅越多；体型方块（小型 1 灰 / 中型 2 蓝 / 大型 3 金）保留。已移除“高概率产出枪械 / 可能产出枪械 / 少量枪械”标签。区块数、楼层数、容器数仍在副标题与详情页显示。
- 建筑详情按楼层折叠，容器点开才加载物品（几千条数据也不会卡）。
- 多体建筑（如社区中心、赌场）可以切换「区块」，不同区块的掉落是独立的。
- 物品行显示：游戏内贴图、名称、NBT 变体（弹药口径 / 附魔 / 药水）、数量范围、实际掉落概率。
- 点物品进入详情：全图所有掉落点，按掉率和平均数量排序，显示区域、楼层、容器、权重、条件概率；NBT 变体也带对应图标。
- 搜索支持中文名、英文 ID、NBT 内容（例如搜「5.56」「附魔」「弹药」）。
- 贴图从本机 11.19 整合包提取：2,116 种战利品物品、66 种方块、300 个 TACZ 枪械/弹药/配件变体；加上套装部件、近战/饰品与防御工事，图集共建立 2,174 条图标映射。家具等 3D 物品使用其材质作为代表性图标。

## 七、常见问题

**Q：手机提示“无法安装” / 没有安装入口？**
需要通过 `http://` 或 `https://` 打开。`file://` 直接打开的单文件版不能安装，只能当网页用。

**Q：安装后更新了数据，但手机还是旧的？**
修改 `app/sw.js` 的 `CACHE` 版本号，重新部署；或者在手机浏览器里清除该站点数据后重新安装。

**Q：收藏/自制内容丢了？**
数据存在浏览器 localStorage。换浏览器、清理站点数据、使用无痕模式都会丢。建议定期「导出备份」。

**Q：能不能多台设备同步？**
当前不能。可以用「导出备份」→ 另一台设备「导入备份」手动同步。

**Q：战利品概率为什么有 100% 和 0.x%？**
表内的「实际掉落概率」是计算后的结果，受权重、条件概率、池子数量影响。详情页同时保留了权重和条件概率，方便对照。

**Q：为什么有些装备 / 载具没有配方？**
近战配方优先来自 KubeJS `weapon_*.js`（141 件中 113 件），载具来自 MTS `config/mts/craftingoverrides`（81 辆）与 Immersive Aircraft shaped recipe（7 架），合计 **109 / 118**；OAmP 节能线与大众巴适的 `commonMaterialLists` 为空，没有可信配方。装备没有配方数据时，通常只能通过战利品、交易、任务奖励或创造模式获取，装备页会优先提示可搜刮建筑。

**Q：改枪台数值和游戏里按 Z 显示的不完全一样？**
改枪台按 TACZ 的 `index` / `data` / `attachments` 文件计算，换弹时间优先采用 `script_param`，后坐力取曲线峰值，散布取对应姿态的基础值；不同枪包、脚本逻辑与整合包版本可能有差异，最终以游戏内 Z 键面板和实测为准。推荐方案是按数值倾向自动挑选的，不是唯一解。

**Q：为什么有些怪物没有图片？**
167 条图鉴怪物已全部配图；极少数使用实体贴图局部或粒子效果重建的示意图，图注会明确说明，避免把示意图当成官方立绘。

**Q：为什么有些物品没有图标？**
当前版本已为战利品表中的 2,116 种物品、66 种方块、300 个 TACZ NBT 变体，以及套装部件、近战/饰品与防御工事建立图标映射（图集共 2,174 条映射）。少数 3D 家具/设备使用其材质作为代表性图标；如果仍然看到名称首字占位，说明该条目是前端自制或导入的本地补充内容。

**Q：音乐可以商用吗？**
不可以。7 首配乐版权归 TqLxQuanZ 所有；本工具仅用于个人非商业攻略试听，请勿提取、二次分发或商用。贴图、剧情和怪物截图同样版权归各原作者，本 APP 仅用于个人非商业查阅，如有侵权请联系删除。

亡者世界图鉴 · 网站部署说明
==============================

一、这是什么
本压缩包是「亡者世界图鉴」的静态网站版，解压后把里面的全部文件上传到网站根目录即可访问。
入口文件：index.html
不需要数据库、不需要后端；纯 HTML/CSS/JS + 图片/音频，支持手机与电脑浏览器。
图片已统一转为 WebP，体积更小，低网速加载更快。

二、部署步骤
1. 解压本压缩包。
2. 把解压出来的所有文件（不是外层文件夹）上传到网站根目录，例如：
   /public_html/
   /www/
   或 GitHub Pages / Cloudflare Pages / Vercel 的静态站点目录。
3. 访问 https://你的域名/ 即可。
4. 如果放在子目录，例如 https://你的域名/guide/，把文件放到 guide/ 下即可，页面使用相对路径。

三、PWA / 离线安装
- 浏览器要求 HTTPS（localhost 除外）才能注册 Service Worker。
- 首次打开后，浏览器会缓存页面与资源；之后可「添加到主屏幕」。
- 更新数据后请同时更新 sw.js 的缓存版本号，避免用户继续看到旧缓存。

四、文件说明
index.html              入口
manifest.webmanifest    PWA 配置
sw.js                   离线缓存
css/ js/ data/          页面、脚本与数据
images/ textures/       图片（WebP）
audio/                  音乐

六、本地预览
Windows 可双击 start-server.bat，然后访问 http://localhost:8080/
不要直接双击 index.html（file:// 下部分功能与音频会被浏览器限制）。

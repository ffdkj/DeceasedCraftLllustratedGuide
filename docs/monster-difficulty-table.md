# 怪物难度数据表（生成物，勿手改）

- 生成：`tsx scripts/gen-monster-difficulty.ts`，生成时间 2026-10-22
- 数据源：`kubejs/startup_scripts/entity/attribute.js`（基础属性）、`config/incontrol/spawn.json`（区域/难度倍率）、`config/hordes/data/hordes/horde_data/{tables,scripts}`、`config/hordes-common.toml`
- 机读数据：`public/data/monsters-difficulty.js`（`window.WZ_MONSTER_DIFF`，132 个实体；未接入站点）

## 1. 口径

| 项 | 说明 |
|---|---|
| 血量 / 护甲 | 属性值（`generic.max_health` / `generic.armor`），已并入 InControl 倍率 |
| 攻击 | 属性值（`generic.attack_damage`），已并入倍率 |
| 打向玩家 | 攻击 × 原版难度系数（简单 `min(D, 0.5D+1)`、普通 `D`、困难 `1.5D`），不含玩家护甲 |
| 城市内 | 命中区域标签 + `incity`：普通难度只有僵尸/尸壳/溺尸吃 `finalize` 批，困难难度全部 hostile 再吃一批 |
| 野外 | 无区域标签：血量/护甲/攻击不到 InControl 的区域倍率（简单仍 ×0.5） |
| 尸潮 | `spawntype: event` 在困难下额外 ×2 血 / ×1.5 甲 / ×1.5 攻击；简单再 ×0.5 |
| hostile 判定 | 除 `naturalist:*` 动物外，其余实体都按 `hostile: true` 处理（困难批只对 hostile 生效） |
| 尸潮 | 实测不吃 `finalize`（区域）那一批，只吃 `onjoin` 批：困难 = 区域 × 事件，普通 ×1，简单 ×0.5 |
| 尸潮 · 野外 / 城区 | 野外没有区域标签；城区是尸潮落进区域标签范围，困难时叠区域倍率 |

每场尸潮：20 只/次 × 5 次 ≈ 100 只，同屏上限 150，每 15 天一次。
